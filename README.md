# 石川漁業シミュレーション（FISHxTECH）

石川県の漁業の実データを使って、漁業会社の経営を体験できるブラウザゲームです。
漁場・漁法・魚種を選んで出漁し、天候や相場の変動、ランダムなイベントを乗り越えながら会社を大きくしていきます。

> **Fish×Techハッカソン #いしかわの海の幸をアプデせよ（石川県・金沢市 共催）**
> 23チーム中 **Civic Tech Innovation Award** 受賞（2026年3月）
> 「漁業とデータの関係を直感的に学べる」点が評価されました。日本経済新聞に掲載。

## 特徴

- **実データに基づく設計**：石川県の漁業統計（2005〜2025年の水揚げ量・金額）と水産物の卸値データをもとに、海域ごと・季節ごとに獲れる魚と単価を設計
- **石川の海を再現**：加賀海域・七尾湾・能登内浦・能登外浦・志賀海域の5海域、定置網・底曳網・イカ釣など7種類の漁法、19種の魚
- **経営シミュレーション**：燃料費・人件費・借金・天候・価格変動を考えながら毎月の出漁を判断。クルーの雇用（21人）、設備の強化（18種）、イベント（47種）、月間チャレンジ
- **ミニゲーム**：反応・記憶・順番当てなど、イベントごとのミニゲーム
- **ランキング**：会社名とスコアを登録して、ほかのプレイヤーと競える（ノーマル／激ムズ）

## 使用技術

| 領域 | 技術 |
|---|---|
| フロントエンド | TypeScript, Vite（フレームワークなし） |
| バックエンド | Python, FastAPI, SQLAlchemy, Pydantic |
| データベース | MySQL 8.0 |
| 実行環境 | Docker Compose（フロント / API / DB の3コンテナ構成） |

## 起動方法

Docker が入っていれば、次のコマンドだけで起動できます。

```bash
docker compose up --build
```

起動後、ブラウザで http://localhost を開きます。

> `backend/.env.docker` と `docker-compose.yml` に書かれている DB のパスワードは、ローカル開発専用の値です。

### 個別に動かす場合

```bash
# フロントエンド
cd frontend
npm install
npm run dev        # http://localhost:5173

# バックエンド（別のターミナルで）
cd backend
cp .env.example .env   # DB の接続情報を書き換える
pip install -r requirements.txt
uvicorn main:app --reload
```

## ディレクトリ構成

```
frontend/
  src/game/     ゲームのデータ・進行ロジック・ストーリー・サウンド
  src/ui/       画面描画（App.ts）・ドット絵スプライト
  src/api/      ランキング API の呼び出し
backend/
  main.py       FastAPI アプリ本体
  routers/      ランキング API（入力値の検証つき）
  models.py     スコアのテーブル定義
```

## 使用データについて

ゲームの数値は、Fish×Techハッカソンで主催者から提供された石川県の漁業統計（水揚げ）と水産物の卸値データをもとに設計しています。
元のデータはハッカソン参加者向けに提供されたものであるため、このリポジトリには含めていません。ゲームで使う値は `frontend/src/game/data.ts` に設計済みの形で入っており、起動にデータファイルは必要ありません。
